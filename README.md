# Diagrama de Classes — Sistema de Recursos Humanos

## Sobre o projeto

Projeto acadêmico individual desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com o objetivo de praticar modelagem de sistemas utilizando UML.

O diagrama representa a estrutura de um sistema de Recursos Humanos, contemplando classes relacionadas a funcionários, departamentos, cargos, folha de pagamento, controle de ponto, benefícios, recrutamento e outras funcionalidades de gestão de pessoas.

## Ferramenta utilizada

- Draw.io (diagrams.net)

## Objetivo

Representar a estrutura de um sistema de RH por meio de classes e seus relacionamentos, aplicando conceitos de análise e modelagem orientada a objetos.

## Arquivo

- `diagramadeclasseRH.drawio` — arquivo editável do diagrama.
